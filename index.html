Shorts Uploader

A private tool that uploads short videos (YouTube Shorts) to YouTube channels owned and operated by its developer, using the YouTube Data API. This tool uses YouTube API Services.

AboutPrivacy PolicyTerms of Service

About

Shorts Uploader is a single-operator automation script. It uploads and schedules videos to YouTube channels that the operator owns or is authorized to manage. It has no public users, accounts or sign-up, and is not offered as a service to third parties. It calls the YouTube Data API (videos.insert with a scheduled publish time, plus read-only status lookups of the operator's own videos).

Privacy Policy

Last updated November 2, 2026.

Data we access

Through Google OAuth the tool accesses only the Google account that owns the operator's channels, with the youtube.upload and read-only YouTube scopes. It reads the operator's own channel and video metadata (titles, IDs, publish status) to confirm uploads.

How data is used and stored

YouTube API data is used only to run uploads and confirm their status. OAuth tokens are kept in an encrypted credential vault. API data is not sold, shared with, or disclosed to third parties, and is not used for advertising or profiling.

YouTube API Services

This tool uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. See also the Google Privacy Policy. You can revoke the tool's access to your Google data at any time in your Google security settings.

Data deletion
